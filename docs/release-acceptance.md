# سجل قبول مارك ربوت لشركة WOW FURNITURE

**في 21 نوفمبر 2026 نُشرت البنية الخلفية للإصدار 211 من خط أساس `main` عند `c7ea6e7ab2349d6b461d78c1245653bd3c6e4caa`؛ وما زال قبول الاستخدام السحابي والنقل مفتوحًا.** النظام مخصص لعمل الشركة الدائم، وعرض التخرج أحد استخداماته. العنوان السابق `galeri.wowfurniture.com.tr`، والعنوان النهائي `markrobot.wowfurniture.com.tr` الذي أصبح مسجلًا في `CNAME` على `main` عند `8e1a5b8c54519ea03c6ab9c24790c97d73c3d518`. سبق تأكيد تطابق 425 ملفًا من خط الأساس مع التزام `main` الأصلي `39ff395b76f25c5774cf3de2fe15c6d8c5ed9c9d`؛ يخص ذلك شيفرة التطبيق الأساسي فقط. تهيئة الاتصال العام ما زالت `enabled:false`. ## سجل نشر البنية الخلفية

نجح تطبيق `mark_robot_release_211` بالإصدار `20261121190038` على المشروع المقصود `sldthbnigivpsqixccah` بعد وصول تجربة التراجع الكاملة المنقحة إلى علامة النجاح. ملفات SQL الإنتاجية الاثنا عشر لم تتغير عن خط الأساس المذكور. نُشرت `wow-cloud` بحالة `ACTIVE` والإصدار 1، بالمعرّف `7c82fef5-4e0d-4884-8f6e-fbe217bf0c2d` وبصمة حزمة SHA-256 ‏`9a87e08d382112f7364fa63d0396621ceed20c8bae2b5fd2398acf7747c49805`.

عند `2026-11-21T19:01:27Z` رُصدت النتائج التالية على نقطة Edge المنشورة:

| الفحص | النتيجة |
| --- | --- |
| `GET /health` | `200` مع `ok:true` و`service:mark-robot` و`checkedAt` |
| `POST /health` | `405` |
| `session.snapshot` و`gallery.snapshot` دون توثيق | `401` |
| `OPTIONS` من العنوانين القديم والجديد | `204` مع CORS مطابق للأصل المطلوب |
| طلب من أصل غير مسموح | `403` |
| `POST /push-worker` دون الرمز الخاص | `401` |

أكد تدقيق ما بعد التطبيق تطابق الأعداد وبصمات SHA-256 لجميع الجداول القديمة الـ84 وبيانات التعريف لكائنات Storage الـ163. بقيت الحاويات السبع وسياسات التخزين القائمة مطابقة؛ لم تُجلب بايتات الملفات ولم تُحسب بصماتها من جديد. بقيت بصمات مستخدم Auth الموجود وجلساته الـ34 ومشغّله مطابقة. الجداول الجديدة الـ62 جميعها مفعّل فيها RLS؛ الدوال الـ97 لا تمنح `EXECUTE` إلى `anon` أو `authenticated`، والمخططات الخاصة السبعة لا تمنحهما `USAGE`. العروض الستة في `public` تستخدم `security_invoker=true`، والعروض الداخلية الثلاثة خاصة بلا منح للمتصفح. وظائف WOW الخمس في Cron مفعّلة؛ نجحت وظيفة المراسلات عند 19:01 و19:02 UTC دون فشل مرصود، وبقية الوظائف لم تُرصد دوراتها بعد. أعاد فحص الصحة صفر ملاحظات، ولم تظهر أخطاء أو تحذيرات جديدة في الفحص. بقي عدد مساحات WOW وحساباتها وخانات أسرارها في Vault صفرًا.

هذه أدلة جاهزية البنية وعزل الطلبات وحفظ الحالة القديمة أثناء الإضافة. لم يُنشأ مالك أو مساحة عمل WOW حية ولم تُضبط أسرار التطبيق أو مفاتيح Web Push في هذه الخطوة. يمكن أن ينجح `/health` دون مساحة عمل نشطة، فلا يثبت نبض مساحة فعلية أو نجاح دخول المالك. يبقى قبول Auth وStorage والأجهزة والنسخ والاستعادة والنقل والمزوّدات مطلوبًا.

حدّث الالتزام `8e1a5b8` ملف `CNAME` عند `19:02:58Z`. أثبت فحص `19:05:04Z` سجل CNAME إلى `wowmobilya.github.io` بقيمة TTL ‏300 وإصدار منطقة `2026112101`، ونجح HTTP للعنوان الجديد برمز `200`. أعاد فحص HTTPS عبر الوكيل `503` وهو قيد التحقق؛ أعاد العنوان السابق `404` عبر HTTP وHTTPS دون تحويل. يبقى قبول HTTPS ونقل بيانات الأصل السابق معلقًا.

### توضيح التنبيهات المالية والتطوير الاختياري

في `accounting.html` العام، يحفظ `saveNotifications()` خياري `notif_overdue` و`notif_salary` دون مسار يرسل تنبيهًا لهما؛ ويعدّل `checkOverdue()` حالة الفاتورة في الذاكرة فقط. يستهلك فحص متصفح كل خمس دقائق `notif_balance` لعرض تحذير منخفض الرصيد أثناء فتح الصفحة. يغطي تحذير الصناديق الأصلي الحالي الوظيفة العملية بعتبات مستقلة ووحدات مالية دقيقة. لم يثبت المصدر العام تذكيرات خادم مجدولة؛ لا يمكن إثبات أو نفي وجود وظائف خاصة غير مرئية دون الوصول إلى المشروع. [مصفوفة المصدر](galeri-feature-merge.md) · [عرض المالية الحالي](../modules/finance/workspace.js)

إضافة تذكيرات خادم اختيارية للفواتير أو الأرصدة أو الرواتب **تطوير جديد غير منفّذ أو مفعّل**، وليست شرطًا لإطلاق الإصدار الأساسي. إشعارات البروفرما والدفعات والمصروفات عند اعتماد الحدث منفّذة بالفعل؛ يبقى قبولها على هاتف مغلق التطبيق ضمن بوابات النشر أدناه.
