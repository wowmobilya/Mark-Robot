# Zebra thermal roll profiles

Choose the paper dimensions that match the printer driver. The 100 × 150 mm profile prints a portrait page. The 150 × 100 mm profile prints a landscape page with the original Home Center artwork upright. Each package gets one label. A nine-package job generates nine pages in invoice-line, packet and unit order.

| Measurement | Zebra 100 × 150 | Zebra 150 × 100 |
| --- | --- | --- |
| Page and label size | 100 × 150 mm | 150 × 100 mm |
| Artwork rotation | 90° | 0° |
| Uniform enlargement | 46.53% | 46.53% |
| Final artwork bounds | 97 × 142.13 mm | 142.13 × 97 mm |
| Left and right clearance | 1.50 mm | 3.94 mm |
| Top and bottom clearance | 3.94 mm | 1.50 mm |

Both profiles use the specified 250-label roll capacity. A 251-package invoice generates 251 label pages and can continue onto the next roll. The print document uses zero page margins and one cell with zero grid gap. The printer driver controls the physical gap between labels.

The renderer scales the complete original 97 × 66.2 mm artwork by 97/66.2. Both logos, the product photograph, text, borders and CODE128 image follow the same transform. The artwork keeps its original colors for preview and printing. The thermal printer driver handles monochrome conversion. Print at actual size using the matching media dimensions.

## Verification

- All 26 core and paper-profile tests passed. Both Zebra orientations were checked for page dimensions, artwork bounds, safe insets, nine individual packet labels, barcode identity and a single-page preview. Counts were checked for 0, 1, 249, 250, 251 and 2,000 labels. The last page has no forced break after it.
- TW-2004 remains the default. Both Tanex profiles generated byte-identical UTF-8 print HTML compared with release 199 commit `c223bfb` for 1, 4, 8, 9 and 36 labels. The comparison included the customer and issuer logos, product photo, color and local barcode.
- The dimensions above describe generated HTML and calculated artwork bounds. Physical thermal registration and barcode scanning on Zebra hardware remain unverified.
