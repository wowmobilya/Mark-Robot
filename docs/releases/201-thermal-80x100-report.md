# Thermal 80 × 100 mm package labels

The 80 × 100 mm thermal profile prints one Home Center package per portrait label. Each page contains the original 97 × 66.2 mm artwork at 100% scale, rotated 90°. The printed artwork occupies 66.2 × 97 mm and is centered with 6.9 mm of clearance on each side and 1.5 mm at the top and bottom.

Use the 80 × 100 mm media setting and actual size in the print driver. The print document applies zero page margins and a zero grid gap. The driver handles the distance between physical labels. Roll capacity is unspecified for this size. The print job uses the invoice quantity and packet counts.

The profile ID is `thermal80x100`. All three thermal profiles expose `mediaType: 'roll'`. The two Zebra profiles retain the specified 250-label capacity.
