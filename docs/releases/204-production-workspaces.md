# WOW Galeri — الإصدار 204

أضيفت ثلاث صفحات مستقلة مستوحاة من وظائف الملف المرفق، باستخدام هوية WOW الحالية ولغات الواجهة الخمس.

## ما أُضيف

| الصفحة | الاستخدام |
| --- | --- |
| بطاقات التصنيع | إنشاء بطاقة من فاتورة محفوظة، متابعة كل بند: قيد الانتظار، قيد التصنيع، مكتمل؛ ملاحظات وسجل تغييرات وطباعة A4 للورشة. |
| مكتبة المواد والخامات | حفظ المواد ووحداتها وأسعارها وعملاتها، اختيارها داخل كلفة المنتج، وتطبيق تحديث السعر بقرار واضح. |
| تحليل الكلفة والربح | مقارنة كلفة الوحدة بأسعار A وB وC، عرض ربح الوحدة والهامش، وفرز المنتجات ذات الكلفة الناقصة أو البيع دون الكلفة. |

تبقى صفحات إتيكيت الطرود، كلفة المنتجات وأرشيف الفواتير مستقلة. أصبحت المجموعة ست صفحات، مع الرجوع والتنقل وأزرار الصفحة المناسبة على الهاتف.

## دقة البيانات

- بطاقة التصنيع تحفظ بيانات بنود الفاتورة الأصلية وصورها وألوانها وكمياتها وأبعادها. تغيير المنتج لاحقاً لا يبدّل البطاقة المحفوظة.
- حالة التصنيع مستقلة عن حالة التسليم والمخزون والدفعات.
- أسعار المواد الجديدة لا تعيد تسعير المنتجات أو الفواتير تلقائياً. يظهر تطبيق السعر الجديد داخل كلفة المنتج، ثم يُحفظ التغيير صراحةً.
- الكلفة أو السعر غير المدخلين يظهران كبيانات ناقصة؛ الصفر المدخل قيمة فعلية.
- الحفظ من صفحات الفواتير والدفعات والإعدادات القديمة يحافظ على أحدث بطاقة تصنيع ومكتبة مواد داخل معاملة الحفظ نفسها.
- نشر البيانات بعد تحميل الصور يحترم التعديلات أو الحذف الذي حدث أثناء الانتظار. الملاحظة غير المحفوظة التابعة لفاتورة حُذفت تبقى قابلة للقراءة والنسخ والتجاهل الصريح.
