# إرسال كشف الحساب في موعد محدد

من كشف حساب العميل، اختر الفترة والعملة واللغة ثم «جدولة كشف الحساب». تعرض المعاينة نسخة PDF التي ستصل للعميل. حدّد قناة الإرسال والموعد بتوقيت الجهاز، وراجع عنوان العميل أو رقمه وأكّد موافقته. تظهر المواعيد الخاصة بهذا العميل في نافذة الجدولة، ويمكن إلغاء الإرسال وهو في الانتظار. يفحص السيرفر صلاحيات الموظف وبيانات الاتصال عند الجدولة وعند التنفيذ.

الجدولة لمرة واحدة. تحتفظ المهمة بنسخة ثابتة حتى التنفيذ، وبحد أقصى 2 ميبيبايت. تُحسب النسخة ضمن حصة التخزين وتُحرّر عند الإلغاء أو انتهاء محاولة الإرسال. يؤكد قبول المزوّد استلام طلب الإرسال فقط. عند التباس النتيجة تُسجّل المهمة «غير مؤكدة» وتحتاج إلى مراجعة لدى المزوّد قبل إعادة الإرسال.

## إعداد قنوات الشركة

تُضبط القنوات في أسرار وظيفة Supabase الموجودة باسم `wow-cloud`. كل قناة مرتبطة بمعرّف شركة واحدة. يجب أن يكون للعميل عنوان محفوظ أو رقم دولي صالح. يستطيع المستخدم المخوّل تنزيل PDF أو مشاركته يدويًا عند غياب إعدادات الإرسال.

| القناة | الإعدادات |
| --- | --- |
| البريد | مفتاح `RESEND_API_KEY`، عنوان مرسل موثّق في `WOW_STATEMENT_FROM_EMAIL`، معرّف الشركة في `WOW_STATEMENT_EMAIL_WORKSPACE`، والتفعيل الصريح `WOW_STATEMENT_EMAIL_ENABLED=true`. |
| واتساب | رمز الخادم `WOW_WHATSAPP_TOKEN`، معرّف رقم النشاط التجاري `WOW_WHATSAPP_PHONE_ID`، إصدار Graph API المدعوم في `WOW_WHATSAPP_GRAPH_VERSION`، معرّف الشركة `WOW_WHATSAPP_WORKSPACE`، اسم القالب المعتمد `WOW_WHATSAPP_TEMPLATE` ولغته `WOW_WHATSAPP_TEMPLATE_LANGUAGE`، ثم `WOW_STATEMENT_WHATSAPP_ENABLED=true`. يلزم قالب مستند بترويسة PDF ونص ثابت. |

تفحص مهمة `wow-customer-correspondence` المواعيد المستحقة كل دقيقة وتستدعي عامل الإرسال المخوّل. تنتهي المواعيد المتأخرة لأكثر من 24 ساعة دون إرسال. تُظهر نقطة `health` جاهزية إعدادات القناتين دون عرض مفاتيح أو عناوين العملاء. يبقى التحقق من وصول بريد أو رسالة واتساب حقيقية مرتبطًا بإعداد المزوّد وموافقة عميل محدد.
