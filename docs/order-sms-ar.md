# إرسال رابط الطلب عبر Netgsm

من شاشة طلبات المعرض، يفتح الموظف المخوّل معاينة الرسالة ويتحقق من الرقم المحجوب واسم المرسل، ثم يؤكد موافقة المستلم. يستخدم النظام رقم حساب المشتري المحفوظ. يتيح الرابط تنزيل نسخة HTML قابلة للطباعة من بنود الطلب المعروضة لمدة ساعة. تصبح النسخة غير متاحة عند إلغاء الطلب أو أرشفته أو تغيير إصداره أو رقم المستلم أو تعطيل الشركة. يُعامل الرابط باعتباره خاصاً بالمستلم.

## إعداد الخادم

تُحفظ القيم التالية في أسرار وظيفة Supabase. لا تُحفظ في المستودع أو المتصفح.

- `WOW_NETGSM_TENANTS` كائن JSON بمفتاح لكل معرّف مساحة عمل. يحتوي كل إدخال على `username` و`password` لمستخدم API الخاص بالشركة ومصفوفة `senders` لأسماء المرسل التي اعتمدها Netgsm. الاسم الأول هو الافتراضي.
- `WOW_ORDER_LINK_SIGNING_KEY` مفتاح عشوائي خاص لا يقل عن 32 محرفاً. يؤدي تغييره إلى إبطال الروابط السابقة.
- `WOW_NETGSM_ENABLED` يُضبط إلى `true` عند جاهزية الحسابات والموافقة على تفعيل الإرسال.

يتحقق الخادم من الاسم المختار بقائمة المرسلين المعتمدة لدى Netgsm قبل الإرسال. يتطلب الإرسال موظفاً لديه صلاحية تعديل الطلبات ورقم حساب مشتري صالحاً. يحد الخادم الطلب الواحد بثلاث محاولات في 24 ساعة والشركة بمئة محاولة في تلك المدة. عند انقطاع الاتصال بعد بدء الإرسال يعرض النظام نتيجة غير مؤكدة، ويتولى المسؤول التحقق من سجل Netgsm قبل طلب إرسال جديد. تعني الحالة «مقبول» أن المزود قبل الطلب. قد يحتسب المزود أكثر من مقطع SMS وفق طول الرابط وترميز اللغة.
